# @mgood-pi/core

Shared, framework-neutral contracts for `@mgood-pi/*` packages.

This is primarily an implementation dependency, rather than a Pi package users install directly. It is versioned and published independently so plugins can declare stable npm dependencies.

## Development

```bash
npm run test --workspace @mgood-pi/core
npm run build --workspace @mgood-pi/core
```

See the root [README](../../README.md) and [release guide](../../docs/releasing.md).
